Thim static-copy fixture. The title is the only dynamic value; the rest is UTF-8 that the renderer should copy as byte ranges.

Why this page exists

Most of a finished document is static markup. Thim stores that markup as UTF-8 and copies ranges into the response buffer. This template is long enough to keep that path on the hot side of a microbenchmark without hiding the encoder behind a huge list.

Repeated paragraphs follow so the compiled resource is several kilobytes. They stay identical on purpose so the compiler can reuse byte ranges.
